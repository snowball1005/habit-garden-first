# 첫째 자기주도 공부 정원 — PWA + 오프라인 체크

GitHub → Render Static Site, Publish Directory: `public`

## 주요 기능
- 홈 화면에 설치 가능한 PWA (`manifest.webmanifest`, `sw.js`, 앱 아이콘)
- 최초 온라인 로그인 및 앱 방문 후 오프라인에서 기존 로그인·최근 기록 확인, 목표 1~3개 선택, 완료 체크
- 오프라인 수정은 브라우저 localStorage의 사용자별 대기열에 저장되고, 다시 온라인 상태가 되면 자동 전송 시도
- 일요일 보고서와 부모 피드백 기록도 오프라인에서 작성할 수 있지만 전송은 인터넷이 연결되어야 함
- 부모가 다른 기기에서 볼 수 있는 것은 **서버로 전송이 완료된 기록만**입니다.

## 설치
1. Supabase 설정값을 `public/index.html`에 입력한 후 GitHub에 업로드
2. Render Static Site 배포(Publish Directory `public`)
3. 휴대폰 Chrome(안드로이드) → ⋮ → 홈 화면에 추가/앱 설치
4. iPhone Safari → 공유 버튼 → 홈 화면에 추가
5. 온라인에서 첫 로그인 및 기록 동기화 후 오프라인으로 테스트

## 주의
- Supabase 최초 인증/가입, 부모 원격 조회, 서버 동기화는 인터넷이 있어야 함.
- 브라우저 저장소 초기화, 앱 삭제, 시크릿 모드, 기기 변경 시 **아직 전송되지 않은 기록이 소실될 수 있음**.
- 외부 JS 라이브러리 모듈은 최초 온라인 방문에서 브라우저/서비스워커에 캐시되며, 브라우저 종류에 따라 최초 오프라인 재실행이 제한될 수 있습니다.
- 동일 목표를 여러 기기에서 오프라인으로 편집하면 마지막 서버 전송 값이 우선할 수 있습니다.
- 개인정보가 들어 있는 기기에서는 기기 잠금 사용을 권장합니다.
